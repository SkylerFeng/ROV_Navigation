# slalom 超时：执行进度协调与感知、初始状态修正

> 后续实际运行发现转向复发，本页结果属于历史版本。本轮进一步修复低速朝向、引导拐角与终端接近，并完成三种发目标时序及五场回归，见[最新修复记录](slalom_turn_fix_20261015.md)。

> 正式入口更新（2026-10-15）：修正后的门洞已替换 `gates`，不再提供 `gates_clearance` 场景入口；slalom 使用当前默认修正配置。本页历史命名、旧命令和对照数据仅供追溯，当前运行与汇报见[组会汇报](group_meeting_ROV_navigation.md)。

上一轮 slalom 在 180 s 后仍距目标 6.4045 m，处于反复转向、保持和重规划中。中间版本曾两次到达，但随后 baseline 回归暴露了全局直线引导的问题。最终增加已观测地图引导；最终回归五场全部到达，见[最终五场回归报告](navigation_five_scenarios_20261015_guide_fix.md)。不能把中间版本两次成功当作最终版本的重复验证。

## 为什么会反复停住

1. 跟踪器要求相机朝向与平移方向相差不超过 20°，转向时将 XY 速度设为零；此前 EGO 与轨迹服务器却继续按仿真时间采样。名义位置越走越远，达到 0.25 m 跟踪偏差后停车、重新生成轨迹，打断尚未完成的转向。旧运行累计 24 次跟踪恢复；最终姿态仍未对准新参考。
2. 只修正执行进度后，机器人能通过原先停滞区，但约 110.48 s 与原水池网格发生真实接触，最大冲量约 0.472 N·s。原网格仅单面渲染；建图上限 1.24 m 低于船体顶部约 1.246 m，且步长 4 会漏采细结构。
3. 补齐双面渲染、船体高度覆盖与采样后，窄视场下仍会太晚看到侧前方障碍；实测膨胀地图显示当前位置后来变为占用，EGO 无法从占用起点继续生成轨迹。
4. 扩大视场后，旧起点下首条轨迹也可能无法生成。地图快照显示旧起点格为空闲，但离原水池结构膨胀边界很近；日志有固定控制点占用和 A* 失败。把起点 X 后移 0.3 m 的对照可生成首条轨迹并完成。该对照支持采用更有余量的初始化，尚不能单凭它把每次失败都归结为某一网格舍入。
5. 全局参考多项式本身不避障，其截取的局部终点可能落在占用区。已增加终点占用防护；这一补丁单独未使旧起点通过，不将其表述为唯一原因。

## 全局引导的补充

转向协调、感知和初始化修正后，slalom 曾两次通过，但 baseline 仍会因观测更新而停在膨胀区附近。因此此前批次 `five_scenarios_20261014_phase_fix` 已标记为中止的诊断批次，不能作为五场均通过的结果。

最终增加固定高度的 0.1 m 平面 A* 引导：输入仅为实际深度建出的膨胀地图；接近占用区域时增加软代价，边按 0.025 m 间隔检查，缩短引导路径时保留横向余量。已知水域边界来自 `config/pool_water_boundary.json`，搜索保留 0.4 m 池边余量；该文件不包含新增障碍位置。路径点提供给 EGO 现有全局参考，局部仍由 EGO 优化 B 样条并进行碰撞检查。未知区域仍沿用现有地图的处理方式，并不构成完整环境可见性保证。

最终 slalom 无窗口实测在 87.23 s 到达，误差 0.001718 m，跟踪恢复由原记录的 24 次降至本轮 1 次，最大接触冲量为零。

## 修改内容

- FSM 在转向等待期间移动局部轨迹起始时刻，使轨迹相位冻结；跟踪偏差检查、周期重规划和碰撞预测使用同一局部起始时刻。
- 通过 `/rov/trajectory_phase` 共享轨迹编号和相位，轨迹服务器按匹配的相位采样；暂停时保留切线参考以完成转向。进度消息失效超过 0.5 s 时以零参考速度保持。
- 朝向未满足条件时不反复周期重规划，碰撞检测、地图更新和新目标回调继续运行。仿真 `/clock` 与 PhysX 没有暂停。
- 原池碰撞网格渲染代理启用 doubleSided，建图高度上限升至 1.28 m，覆盖船体顶部与接触余量；逐像素深度采样成为默认。
- 仿真前视相机水平视场明确设为 90°（实际标定 fx=320，640×360 图像）；旧条件为约 53.03°。
- 当前公共起点为 `(-3.0,0,1)`，目标为 `(3.5,0.4,1)`；运行时同步更新起终点标记。新增障碍布局、船体尺寸、0.3 m/s 上限和 0.5 m XY 膨胀保持。
- 局部终点若占用，沿全局参考寻找后续空闲点；仍需 EGO 优化并检查连接路径。

这是执行逻辑、传感器配置与初始化的联合修正。不能把新旧差异都归功于单一代码补丁，也不能声称旧 53° 视场与旧起点已经稳定通过。

当前自由终点任务允许从障碍阵列外围绕行；完成 slalom 表示该布局下避障到达，不表示强制按 S 形依次穿过各个间隙。

## 运行 slalom

先结束旧仿真和导航进程；三个终端均进入项目根目录。切换后重新启动以清空旧地图。

```bash
# 终端一
bash scripts/select_scenario.sh slalom
bash scripts/start_sim.sh
# 终端二
bash scripts/start_navigation.sh
# 终端三，等待 ROV ready 且点云/里程计持续发布
bash scripts/send_goal.sh
```

自动实测：

```bash
python3 scripts/run_suite.py --scenarios slalom --output-dir logs/suites/NEW_SLALOM_RUN
```

当前默认配置已包含有效起点、目标、90°视场和逐像素采样，不需要额外覆盖文件。历史 `slalom_safe_start.json` 仅用于保留本次对照条件。
