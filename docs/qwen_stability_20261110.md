# LLM 导航稳定性与转向平滑迭代（2026-11-10）

## 问题与设计

此前 `qwen_demo_20261110_165224` 中，目标观测在 API 等待期间过期，接近被拒后切换远处探索；停靠验证失败也未强制局部恢复。近整圈初始扫描、重复对齐和目标切换叠加，造成大量低速转向。

本轮修改：

- 初始/途中 scan 默认从约 351° 改为 120°，扫描预算 25 s；预算用尽转回决策，不继续转圈。没有把任务时限延长。
- 已确认目标的表面位置只作为方向记忆。DECIDING 期间持续指向该目标，并用新鲜观测更新方向，减少等待 API 时看丢目标。
- 新增 RECOVERING：实时校验使接近失效或停靠验证超时后，先保持位置面向记忆方向，再作左右各 25° 的有限搜索。最多 16 s；重新确认后交还 LLM 决策。无有效目标时退出，带 12 s 冷却，避免立即重复打断探索。连续恢复尝试有上限 2；不凭记忆通过成功判定。
- 探索动作至少执行 4 s 才能因新目标打断；防止短时目标波动触发频繁反转。
- 跟踪器最终偏航指令变化率上限 0.4 rad/s²；失效输入安全停止直接生效。未添加平移制动拖尾，未修改水动力执行器参数。
- 新增运动审计脚本 `scripts/analyze_navigation_motion.py`，将实际速度、偏航与 LLM 决策画在相同仿真时间轴上。

## 参数入口

`config/semantic/runtime.json` 的 scan、recovery；`config/navigation/default.json` 的 tracker.yaw_acceleration_rad_s2。详见 config/README.md 和 config/navigation/README.md。

## 证据与指标定义

低速转向时间定义为实测三维速度 <0.03 m/s 且偏航角速度绝对值 >3°/s 的累计时间，包含必要扫描、对齐，并非全部无效时间。累计偏航为角度展开后的绝对变化总量。偏航角加速度 95 分位由实际姿态差分估算，不代表碰撞或舒适度认证。不同任务时长的累计值不能作为完全控制变量的性能结论。

## 回归测试

74 项通用回归通过（tests.txt），另 4 项实际状态机方法测试通过（recovery_state_tests.txt）：失效接近进入恢复、恢复有时限、不凭过期记忆完成、重新确认返回 LLM、恢复次数预算。状态机测试使用合成输入，无云端或物理仿真，不冒充真实遮挡恢复实验。

## 限制

短扇区扫描不保证原地看到所有方向，需要后续移动探索。仍允许必要转向，不承诺完全消除原地转动。视觉漏检根因未通过新训练解决；保持视觉与空间新鲜度校验。理想距离传感器和真实相机位姿假设不变。尚未做多随机种子统计，不应称为稳定成功率。修改留在本地，未提交 GitHub。

## 换目标位置的 GUI 验证

三个本轮 GUI 运行均未触发 recovery_started 或 verification_failed；候选失效/真实漏检的全面鲁棒性仍需更多样本。统计及证据哈希统一保存于该目录的 summary.json。未经单独消融试验，不能将全部改善归因于某一个参数；相对上轮成功运行，减少的低速转向与缩短扫描、方向保持和路径选择共同相关。
