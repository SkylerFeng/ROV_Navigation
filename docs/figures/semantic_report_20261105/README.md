# 语义导航报告配图

本目录由 scripts/export_semantic_report.py 从同一实验 logs/semantic_final_20261104/screened_rule_00 导出。该实验在水面反光修复前完成，采用规则决策、部件级水动力、理想距离图与仿真相机位姿。图中实测指仿真中记录的状态，不是实物测量。未重新运行实验或调用云端 LLM。

## 建议汇报顺序与图注

1. 01_camera_and_detection.png / .pdf：同一次保存的水下 RGB、沿视线距离图与检测标注。黄色管子检测框内的目标表面距离约 0.83 m。这是相机至目标可见表面的距离，不是 ROV 中心距离。距离图为理想仿真测距，不是单目估深或真实水下深度传感器。
2. 02_trajectory_and_decisions.png / .pdf：最终观测地图上的实际运动轨迹，以及扫描、探索、接近决策时间线。星号是最终视觉估计的表面点，不是目标真实中心。背景是最终地图，不能据此推断初始时刻已经知道全部障碍。时间色段表示决策发出至下一决策的区间，不等同机器人持续运动的区间。
3. 03_motion_and_hydrodynamics.png / .pdf：仿真记录的速度、横滚/俯仰，以及模型计算的部件阻力合力和力矩。它说明闭环内存在动态响应，但单次运行不能独立证明水动力精度，也不能把所有姿态变化归因于某一项水动力。

本次实验成功，用时 142.3 s，轨迹长 2.919 m，EGO 更新 17 次，接触记录 0。单次结果不代表统计成功率。

## 数据

- camera_rgb.png：原始保存 RGB，未做亮度增强。
- snapshot_detections.csv：检测类别、颜色、置信度、空间表面点与测距。
- measured_trajectory.csv：时间与世界坐标位置。
- motion_and_hydrodynamics.csv：速度指令、速度状态、姿态与部件阻力/力矩。
- sources.json：输入路径、SHA-256 和证据边界。

原始 latest_sensor.npz 保存 rgb、depth、相机内参 k、相机位置 cp、四元数 cq；四元数顺序为 wxyz。这里只保留最近一帧，不能从它恢复完整相机视频。图中时间为感知日志记录时间，原 npz 未保存独立的相机采集时间戳。

PNG 适合直接插入 PPT，PDF 适合论文或打印。若报告展示反光修复后的新版结果，请使用新版实验材料并明确区分实验版本。
