# slalom 中途反复转向：本轮直接修复与复测（2026-10-15）

本轮以用户实际失败运行 `logs/runs/slalom_20261015_010432` 为依据修复。此前几次成功不足以证明稳定；本轮保留失败和中间验证记录，不以旧成功数据替代。

## 确认的问题与修改

1. **低速朝向依据不一致。** 旧代码在速度低于 0.02 m/s 时改用参考 yaw。约104 s的记录中，它按约−74°参考朝向允许平移，但速度方向约153°，与实际机头约−79°相差129°。现改为所有非保持状态的有效平移都按实际指令方向计算朝向，FSM暂停判定同步使用同一1e-6阈值。原记录有7个TRACKING方向越限采样，本轮五场均为零。
2. **局部目标跳过引导拐角。** 以前截取拟合多项式上的远端点，不能保证保留A*折线拐角。现在沿实际A*路径选择从局部起点可直接通行的前缀，按0.025 m间隔检查占用，子目标速度设为零；仍由EGO生成局部轨迹。无有效引导时不退回盲目的直线参考。
3. **规划失败时连续计算挤占回调。** GEN_NEW_TRAJ改为一次尝试，失败重试间隔至少0.5 s仿真时间，给里程计、地图和共享相位回调留出处理机会。
4. **轨迹软终点与真实目标不一致。** 中间验证到达目标前约9.2 cm后保持，但未完成严格判定。现在到达名义轨迹末端仍未满足条件时重规划；距离目标小于0.2 m且速度小于0.05 m/s时，可生成精确终端B样条。该短轨迹保持起始位置/速度和零终端速度、加速度，按0.01 s采样检查占用、速度与加速度；不移动机器人实际位姿。

正常需要对准方向时仍会暂停平移。本次修复的是错误方向判定与无法推进的循环，并未关闭前视朝向约束。
