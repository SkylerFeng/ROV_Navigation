## 优先排查顺序

1. 决策候选用执行器一致的整段可达性验证，并记录地图版本、失败格点、候选坐标和实际规划路径。observed_guide.h 额外四向 0.1 m 偏移检查是已确认的约束差异，但尚未被证明是每次绕行的唯一原因。
2. 联合记录目标、参考位置/速度、实际位置、偏航和已发布控制量，排查低速停点反向纠偏与惯性越过参考点。不得通过关闭水动力掩盖问题。
3. 无可达候选时区分局部受阻与目标不存在；连续扫描无新信息应触发明确的恢复策略，而非重复同一区域扫描。
4. 对遮挡物后目标保存失败时间窗 RGB/深度、全部原始 YOLO 框及各过滤原因，人工标注可见目标后再统计真正漏检/误检。
