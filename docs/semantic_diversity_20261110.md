# 多场景与自然语言指令验证（2026-11-10）

## 本轮新增能力

原系统 task.json 的 category/color 决定目标，不能将改写 instruction 的实验宣称为自然语言任务理解。现新增 `--instruction`：真实 Qwen/DeepSeek 文本 API 先解析颜色、类别、可选表面距离；保存 instruction.json，再冻结 task.json 启动导航。默认配置与旧命令兼容。不提供场景物体清单或坐标给解析器。

支持：单一颜色（黄/蓝/红）+ 类别（管/箱）的固定深度探索接近，中文/英文、否定干扰、同义词、0.6–1.5 m 表面停靠距离。缺颜色/类别要求 clarify；多目标顺序任务、最近/最大等相对选择、换深度、未知颜色要求 unsupported，不启动导航。模型语义判断仍可能出错；本地只做严格 schema/范围检查，不能保证任意语言都正确理解。
