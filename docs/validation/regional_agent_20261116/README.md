# 区域先验 Agent 验证

同一 `pool_platform_semantic_yellow_box_turn.usda`，相同任务“请靠近黄色方块，距它表面保持一米。”，真实 Qwen API、YOLO、A*/EGO、部件级水动力和 Isaac Sim 相机。三种条件保留相同 Agent 记忆与全部参数，只改变区域先验。目标初始不可见。

三组轨迹与动作时间线见 `comparison.png` / `comparison.pdf`；各自目录有 `trajectory.png`、`last_camera_raw.png`、`latest_detection.jpg`、`agent_trace.md` 和 `audit.json`。

正确提示是西侧设备区，错误提示是东侧设备区。它们是宽范围任务输入，实际目标位置仅供离线审核使用。

## 测试说明

- `tests.txt`：86 项语义模块测试 + 5 项区域 Agent 测试通过。
- `regional_tests.txt`：11 项 Agent 状态机与区域测试通过（包含上述测试的子集，不应重复计数）。
- `discovery_attempt.txt`：首次对整个 scripts 目录运行通配测试时，遇到 3 个独立仿真脚本导入失败（需已构建 ROS 消息或专用 Isaac CLI 参数）；之后使用适合本次修改的模块测试集合。这个全目录尝试没有全部通过，不将其计为成功验证。
- 状态机测试覆盖错误先验逐步扩展并最终释放、已确认目标优先、观测间隔重置确认、定位抖动不触发重规划、稳定的位置变化触发安全保持并重新决策。

每个条件只运行一次。正确先验并不保证一定更快；Qwen 延迟、相机调度、候选点离散化会影响结果。本实验不能估计成功率，也不能证明任意环境下都能自主找全区域。没有覆盖率保证，搜索扩展依据预算；真实水下测距和位姿误差仍未建模。

## 三组常规对照结果

| 区域提示 | 完成时间（仿真秒） | 航程（米） | 接触记录 | 离线审核 |
|---|---:|---:|---:|---|
| 无提示 | 62.6 | 1.983 | 0 | 通过 |
| 正确：西侧设备区 | 64.7 | 2.103 | 0 | 通过 |
| 错误：东侧设备区 | 83.8 | 2.569 | 0 | 通过 |

三组均是四次真实 Qwen 决策：扫描、探索、扫描、接近。错误提示选择了不同观察点，但发现目标后仍优先接近，未被错误区域困住。全部未触发位置变化局部重规划，也未触发默认 45 秒预算下的区域扩展；这些常规实验不证明扩展机制已在实跑发生。

本场景目标离初始位置较近，通过一次探索和两段扫描即可找到。正确区域并未优于无提示；需要更远目标、更多遮挡和多次重复才能评估先验的效率收益。

## 短预算扩展机制实跑

使用同一场景和错误东侧提示，额外加载 `config/semantic/agent_profiles/region_expansion_probe.json`（10 秒预算、一次扩展）。这是机制探针，**不是前三组同参数效率对照的一部分**。

- 17.6 仿真秒：首次扩大提示区域。
- 40.9 仿真秒：释放区域偏好，进入全局搜索。
- 最终 86.8 仿真秒完成，航程 2.569 米；接触记录 0，离线审核 通过。
- 证据：[事件记录](expansion_probe/semantic/events.jsonl)、[轨迹](expansion_probe/trajectory.png)、[Agent 反馈](expansion_probe/agent_trace.md)、[审核](expansion_probe/audit.json)。

局部目标位置更新机制在本批真实导航中未触发，通过状态机测试覆盖；不能声称已获得真实仿真中该触发条件下的性能改进。
